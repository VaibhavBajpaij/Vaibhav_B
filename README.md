## ✨ Portfolio Engineering Features

- **Real-Time 3D Character & Scene (`@react-three/fiber`, `@react-three/drei`, Three.js):** Interactive 3D mesh rendering with Draco compression (`public/draco/`), encrypted model decoding (`public/models/character.enc`), custom environment HDR lighting, and post-processing bloom effects (`@react-three/postprocessing`).
- **Physics & Scroll Choreography (`GSAP`, `@react-three/rapier`, `@react-three/cannon`):** Smooth ScrollTrigger timeline transitions across Hero, What I Do, Career Journey, Tech Stack Physics Sphere, and Work Carousel.
- **Interactive Project Showcase (`Work.tsx`):** Carousel highlighting full-stack, AI/ML, and algorithmic builds with live deployment and source links.
- **Custom Cursor & Responsive UX:** Dynamic magnetic cursor (`Cursor.tsx`), smooth section routing (`Navbar.tsx`), and full mobile/desktop layout adaptability.

## 🚀 Local Development & Verification

```bash
# 1. Clone the repository
git clone https://github.com/VaibhavBajpaij/Vaibhav_B.git
cd Vaibhav_B

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Run TypeScript check & production build
npm run build

# 5. Run ESLint
npm run lint
```
